# Games

بوت ألعاب عربية لديسكورد مع تطبيق iOS مرتبط بنفس الحساب والنقاط والجلسات.

</div>

## الفكرة

المشروع له سطحان رئيسيان:

- بوت ديسكورد للألعاب الجماعية
- تطبيق SwiftUI على iOS

منطق الألعاب مشترك قدر الإمكان بين السطحين. البوت يحول المشاهد إلى صور بينما التطبيق يعرضها كمكونات أصلية.

## البنية

```text
ios/            تطبيق iOS
src/
  api/           API و WebSocket
  dashboard/     لوحة التحكم
  design/        نظام التصميم
  discord/       أوامر وربط ديسكورد
  games/         منطق الألعاب
  guilds/        إعدادات السيرفر
  images/        إخراج المشاهد إلى PNG
  players/       النقاط والحسابات
  scenes/        تعريف المشاهد
```

منطق الألعاب لا يعتمد مباشرة على `discord.js`. هذا يسمح لنفس اللعبة بالعمل من ديسكورد أو من تطبيق الجوال بدون كتابة نسخة مستقلة لكل سطح.

## البوت

يدعم ألعاب كتابة وأدوار وإقصاء وأطوار جماعية بالإضافة إلى أوامر النقاط والإدارة.

الأوامر تعمل بالسلاش وبالبريفكس.

```bash
npm install
npm run setup
cp .env.example .env
npx prisma db push
npm run dev
```

بعد إضافة أو تعديل أوامر السلاش:

```bash
npm run publish:commands
```

## تطبيق iOS

التطبيق مبني بـSwiftUI ويستهدف iOS 26 مع دعم عربي كامل وRTL وLiquid Glass الأصلي.

الأقسام الرئيسية:

- الألعاب
- اللعب المنفرد
- الصدارة
- الحساب

تسجيل الدخول يتم عبر Discord OAuth2 وتخزن بيانات الاعتماد الحساسة في Keychain.

## الجلسات المشتركة

كل لعبة جارية تمثل Session واحدة سواء بدأت من قناة ديسكورد أو من تطبيق الجوال.

طبقة `Surface` تفصل منطق اللعبة عن طريقة العرض. اللعبة ترسل نفس الأحداث بينما كل سطح يقرر كيف يعرضها وكيف يستقبل مدخلات اللاعب.

```text
Game logic
    |
    +-- Discord surface
    |
    +-- iOS surface
```

النقاط تمر من طبقة تسوية مشتركة حتى يبقى رصيد اللاعب واحدا في كل الأسطح.

## الصور والتصميم

ديسكورد يعرض مخرجات الألعاب كصور مركبة. Chromium مسؤول عن تشكيل النص العربي وإخراجه بشكل صحيح قبل تحويل المشهد إلى PNG.

نظام التصميم موجود في:

```text
DESIGN.md
src/design/tokens.ts
```

يمكن معاينة المشاهد بدون تشغيل البوت:

```bash
npm run preview
```

## CI

GitHub Actions يبني تطبيق iOS ويشغل الاختبارات ويلتقط لقطات من المحاكي للمراجعة البصرية.

تطوير iOS يتم من خلال XcodeGen لذلك ملف المشروع يولد من المصدر بدل الاعتماد على تعديلات يدوية داخل `.xcodeproj`.

## ملاحظات تشغيل

- يجب تفعيل Message Content Intent للبريفكس وألعاب الكتابة
- تشغيل API داخل عملية البوت مطلوب عند ربط جلسات ديسكورد المباشرة بتطبيق الجوال
- إعدادات السيرفر والصلاحيات تحفظ بشكل منفصل عن منطق الألعاب

## الحالة

المشروع قيد التطوير ويجمع حاليا البوت وتطبيق iOS والداشبورد وطبقة اللعب المشتركة داخل مستودع واحد.
